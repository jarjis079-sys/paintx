# PaintX
Static paint-quantity calculator (HTML + JS, no backend, no data stored).
- `index.html` – page and styling
- `app.js` – calculation logic (same formulas as the Excel "Calculator" sheet)
- `products.js` – product list (from the Excel TDS list; edit to add products)
Run locally: open `index.html` in a browser. Deploy: import the repo in Vercel (no build settings needed).
